# AliveChat 💬⚡ (Autonomous AI Roleplay Messenger)

> **AliveChat** — современное Android-приложение для реалистичного текстового общения и ролевых игр с ИИ в формате мессенджера. Персонажи не просто отвечают по очереди, а ведут себя как живые люди: отправляют сообщения вдогонку, выставляют реалистичные паузы при наборе текста, уходят по делам, замечают игнор и пишут первыми через системные Push-уведомления даже при закрытом приложении.

## ✨ Ключевые возможности

### 🎭 Живая асинхронная симуляция
- **Сообщения сериями:** ИИ не присылает монолитные книжные простыни, а разбивает речь на несколько коротких сообщений с эффектом «печатает...» и правдоподобными интервалами.
- **Статусы и расписание:** Персонаж сам управляет своим статусом (`в сети`, `отошел`, `занят`, `печатает...`, `был недавно`) и планирует таймер следующей проверки чата.
- **Инициатива и Push-уведомления:** Если вы вышли из приложения или долго не отвечаете, фоновый движок через Android `AlarmManager` пробуждает персонажа — он может обидеться, спросить, куда вы пропали, или скинуть мем. На устройство приходит нативное системное уведомление со звуком и вибрацией.

### 💡 Внутренние мысли (Inner Thoughts)
- Над репликами персонажа отображается интерактивная карточка скрытых мыслей.
- Вы можете узнать, что персонаж думает о ситуации или собеседнике на самом деле, даже если вслух говорит другое.

### 🎨 Material Design 3 (Expressive)
- **Dynamic Color:** Интерфейс плавно адаптируется под палитру обоев устройства (Android 12+).
- **Tonal Surfaces:** Глубина создается тональными поверхностями (`surfaceContainer`, `surfaceContainerLow/High`) без тяжелых теней.
- **Тёмная и светлая темы:** Безупречная поддержка темной темы, включая прозрачные системные бары (Edge-to-Edge).
- **Статусы сообщений:** Индикаторы доставки как в Telegram (отправлено, доставлено, прочитано двумя синими галочками).

### 🚀 Сеть и обход блокировок (Vercel Reverse Proxy)
- **Работает в Беларуси и РФ без VPN:** Из коробки запросы маршрутизируются через встроенный Vercel Edge Reverse Proxy (`ping-proxy`), обходящий ограничения по региону у Groq и Google.
- **Прямые API или собственный прокси:** В настройках можно в один клик переключиться на официальные эндпоинты (`api.groq.com`, `generativelanguage.googleapis.com`) либо настроить собственный SOCKS5/HTTP прокси.

### 🤖 Поддерживаемые модели нейросетей
- **Groq:** Сверхбыстрая генерация с открытыми моделями (`qwen/qwen3.8-27b`, `llama-3.3-70b-versatile` и др.).
- **Google Gemini:** `gemini-3.5-flash-lite` (стабильные мгновенные ответы без перегрузок).
- **Автоматический Fallback:** Если у одного провайдера кончились лимиты или возник сбой сети, приложение автоматически попробует резервный сервис.

### 🔄 Встроенные обновления (GitHub OTA)
- Проверка и установка новых версий прямо из приложения через GitHub Releases с индикатором прогресса загрузки и автозапуском инсталлятора.

### 🔒 Приватность
- Все диалоги, промпты и персонажи хранятся локально в базе данных SQLite на вашем устройстве.
- API-ключи хранятся в защищенном приватном хранилище приложения и никогда никуда не передаются, кроме целевых API.

## 🛠 Технологический стек

- **Язык:** Kotlin 2.1+
- **Интерфейс:** Jetpack Compose, Material Design 3, Compose BOM
- **Фоновые процессы:** Android `AlarmManager`, `BroadcastReceiver`, `NotificationCompat`
- **Сетевой стек:** OkHttp 4, JSON-парсинг через `org.json`
- **Локальное хранилище:** SQLite (`PingDatabaseHelper`), SharedPreferences (`alivechat_settings`)
- **Загрузка изображений:** Coil Compose
- **Инсталляция:** Android `FileProvider` + `ACTION_VIEW`

## 📦 Сборка и установка

### Требования
- Android SDK (API 35, compileSdk 35, minSdk 26 — Android 8.0+)
- JDK 17+
- Gradle (в комплекте через `./gradlew`)

### Сборка Debug APK
```bash
./gradlew assembleDebug
```
Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`

### Установка на устройство через ADB
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Сборка подписанного Release APK
```bash
./gradlew assembleRelease -x test
```
Готовый файл: `app/build/outputs/apk/release/app-release.apk`

### Публикация релиза на GitHub
Для владельца репозитория настроен автоматический скрипт:
```bash
./tools/release.sh "Описание изменений релиза v1.0.0"
```

## ⚙️ Настройка при первом запуске

1. Откройте **Настройки** ⚙️ в правом верхнем углу.
2. Введите ваш бесплатный API-ключ:
   - **Groq:** [console.groq.com/keys](https://console.groq.com/keys)
   - и/или **Google Gemini:** [aistudio.google.com/apikey](https://aistudio.google.com/app/apikey)
3. Нажмите кнопку **«Проверить»** напротив введенного ключа.
4. Нажмите **«Сохранить и закрыть»** и создайте первого персонажа!
